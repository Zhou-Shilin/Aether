# Phone Use：操作手机

## 功能范围与入口

Phone Use 让 Agent 观察手机上的应用并代用户执行点击、输入、滚动、长按和导航。此功能仅在 Android 提供。iOS 的设置和输入框菜单不显示这一入口。

用户在聊天输入框的加号菜单选择 Phone Use，为当前会话选用手机操作能力。此入口在应用级 Phone Use 已开启，且 Alpine 或 Termux 至少有一个就绪时提供；本地环境用于工作空间和截图文件，不要求必须使用 Termux。输入框中的已选标签表示本会话的选择；移除标签只取消本会话的选择。应用级启用、观察与操作偏好在「设置 → Phone Use」管理。

Phone Use 默认启用，但系统无障碍权限仍需用户亲自授予。启动应用、回到前台不会自动弹出授权提示。明确从加号菜单选择 Phone Use，或在设置中手动开启它，才会在缺少权限时请求用户前往系统无障碍设置启用 Aether。权限被撤销后，再次主动选择仍可重新请求；移除标签不请求权限。系统强行停止应用或某些手机的后台限制可能使无障碍服务中断，应用内的开启状态不等于系统权限始终有效。

## 两种操作场景

默认的前台模式直接操作用户正在看的真实手机屏幕，不要求 Root 或 Shizuku。Agent 打开其他应用时，Aether 会进入后台，用户可以看到被操作应用中的真实变化。聊天中不为前台操作创建实时画面或回放卡片。

「虚拟显示」是默认关闭的实验性选项。开启后，Agent 在另一个显示空间打开和操作应用，用户可在 Aether 中观看它的画面。它额外要求 Root 或 Shizuku；这两种授权服务用于准备显示空间和打开应用，实际界面操作仍依赖无障碍权限。

无论普通后台运行偏好是否开启，只要 Phone Use 任务运行中，就保持任务运行通知和后台执行支持，因为操作其他应用本身会使 Aether 离开前台。一般聊天的后台规则见[设置](settings.md)。

## 观察与操作偏好

设置页将基本偏好放在同一组中，虚拟显示放在另一组中。

| 设置 | 默认值 | 用户选择的效果 |
| --- | --- | --- |
| 启用 Phone Use | 开启 | 决定应用是否提供手机操作能力 |
| 输入策略 | 界面元素优先 | Agent 优先读取屏幕中可访问的文字、按钮和输入框；也可改为截图优先 |
| 输出策略 | 元素操作优先 | 优先针对具体按钮和输入框操作；也可改为手势优先，通过屏幕位置操作 |
| 允许切换策略 | 开启 | 允许 Agent 在某一步改用另一种观察或操作方式 |
| 启用虚拟显示（实验性） | 关闭 | 切换为独立显示空间；开启前先完成额外授权 |

关闭「允许切换策略」后，Agent 使用不符合用户偏好的替代方式会得到失败信息，而不是悄悄换一种方式继续。文字输入仍通过可编辑输入框完成，支持中文、表情和清空原内容；输入动作替换目标输入框的内容。

元素优先时，开始观察和操作完成后会返回当前可用的界面信息。截图优先时则提供图像。截图还会保存到工作空间。密码内容在界面信息中隐藏。受系统保护的安全窗口不能截屏。

基础元素操作和手势不要求 Android 11；无障碍截图与按显示空间操作的后台能力要求 Android 11 或更新版本。键盘的 Enter 操作也依赖 Android 11 或更新版本提供的焦点输入支持。

## 前台操作时的屏幕反馈

当一个前台 Phone Use 回合正在运行，且用户已离开 Aether 进入其他应用时，屏幕边缘出现彩色光带，底部出现浅色说明胶囊。回到 Aether、锁屏、停止回合、关闭 Phone Use 或改用虚拟显示时，反馈消失。

边缘光效沿设备实际圆角延伸。进入时从底部向上亮起，再收拢为较窄的流动色带。边缘不拦截触摸，被操作应用仍可响应用户操作。系统关闭动画时，反馈遵从系统偏好。

胶囊显示 Agent 最近一段面向用户的公开说明。工具调用、连接状态或插入引导时保留这一段说明，直到下一段公开说明开始；不拿思考内容、连接信息代替它。没有公开说明且未编辑引导时，只显示边缘反馈。

胶囊使用连续圆角，短文字在最小高度中垂直居中。新内容带有上升、变清晰和淡入的效果；胶囊随文字平滑增高，最多同时显示四行，长内容跟随最新几行。换行适应中文、表情和连续长单词。胶囊出现的展开与淡入约持续半秒，文字增量的显现约为半秒，大小变化约三分之一秒。

键盘出现后，胶囊平滑移至真实键盘上边缘之上，不覆盖输入区域。手机操作的观察信息不包含这些反馈；截屏时暂时隐藏反馈，但真实应用和当时可见的系统键盘仍会出现在图像中。

## 在其他应用上直接追加引导

双击说明胶囊，可以在当前应用上方打开单行引导输入框和系统键盘。此操作不打开 Aether 页面，也不暂停 Agent。

输入框左侧显示装饰标记，右侧按内容切换操作：为空时是取消，有文字时是发送。键盘的发送键也可提交；返回键关闭编辑，回到说明胶囊。提交使用当前任务的 Steer 方式，其在聊天中的含义见[会话](conversation.md)。

引导绑定用户打开输入框时正在观看的那一个会话与运行回合。若该回合已经结束或被替换，不会把旧输入悄悄送给另一个任务。切换运行回合会关闭输入框并清除旧草稿。

发送成功后清空草稿并回到说明；发送时任务已不再运行，则保留输入并提示。取消编辑会暂存当前草稿，在同一回合再次打开时可继续编辑。

只有胶囊区域接受触摸。Agent 进行坐标手势时，胶囊会临时让出触摸，避免挡住操作。全局导航或目标被引导键盘覆盖时，键盘短暂收起，随后带着原草稿恢复；针对具体界面元素的操作不必进行这次切换。

## 虚拟显示的授权与方向

开启虚拟显示时先进入授权子页。用户在 Root、Shizuku 之间选择，点击授权后显示等待状态，过程中不能重复提交。此前选过的方法会被记住；没有选过时默认选择 Shizuku。

只有授权成功，虚拟显示偏好才真正开启，并返回上级页面。失败时保留原因；Shizuku 未安装时提供安装入口，未运行时提供打开入口。切换授权方法会取消前一种方法的待处理授权。Root 授权不会自动配置 Termux，也不修改 Termux 的文件。

开启虚拟显示后，设置页才出现方向选择：跟随设备、竖屏、横屏，默认跟随设备。竖屏或横屏按设备的长短边安排显示区域。改变已保存方向会停止现有虚拟显示，需要重新打开目标应用。前台模式始终使用实际屏幕方向，不受此项控制。

Agent 可以为本次虚拟显示临时选择方向；临时选择持续至停止，不改用户保存的偏好。需要改变已有显示方向时会重建显示空间，应用需要重新打开。无效请求或显示创建失败不会留下新的临时方向。

## 虚拟显示的观看方式

虚拟显示通过聊天中的画面卡片展示运行画面。点击画面，露出「全屏」入口；全屏中无论横屏、竖屏，都完整适配画面，不拉伸、不裁切。

按 Android 返回键或「退出全屏」回到卡片。离开 Aether 会退出全屏，再打开应用不会自动恢复全屏。切换方向后，画面尺寸随实际显示更新，操作位置应与画面一致。

已记录画面的历史回放规则见[回复呈现](response-presentation.md)。关闭预览不等于停止后台显示中的应用。

虚拟显示不支持把系统返回、主屏幕、最近任务等全局导航限制在那个独立显示空间，因此会拒绝这类操作，Agent 应使用应用内的导航控件。前台模式可使用返回、主屏幕、最近任务、通知、快捷设置，以及焦点输入框的 Enter。

## 页面变化、失败与结束

Agent 观察到的控件只针对当前页面有效。页面中的时钟、动画、加载和输入变化，不应单独导致一个仍是同一按钮的目标失效。操作前确认原应用、窗口和目标仍然匹配；弹出的其他应用窗口或对话框可能使原目标不能操作，键盘窗口本身不会使底层输入目标失效。

若一个控件被页面重建，只在原窗口内找到唯一、确切对应的控件时才继续。找不到、出现多个相似控件、目标已隐藏或无法可靠确认时，操作失败，不凭附近位置猜测，也不自动重复已提交的操作。能重新观察时，失败会附带最新页面，供 Agent 重新决定下一步；允许替代策略时，Agent 可再实际调用截图或手势。

多个聊天中的手机操作按顺序执行，避免同一时间争抢界面。撤销无障碍权限或关闭 Phone Use 会释放正在使用的虚拟显示。

结束前台 Phone Use 时，Agent 可以根据用户是否还要查看结果，选择保留当前应用在前台，或明确返回 Aether。普通停止不会自行切回 Aether；要求返回时，只有确认 Aether 已在前台才算成功，系统阻止打开应用时要报告失败。虚拟显示不提供这个返回选项。

旧版本升级时，曾有一次迁移将前台 Phone Use 开启、虚拟显示关闭；迁移完成后，用户明确关闭的选择会保留，不会每次启动被重新开启。
