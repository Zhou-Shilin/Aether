# 定时任务

## 入口与可用范围

定时任务保存一段交给 Agent 的要求，并按计划自动发起聊天回合。用户可以手动管理，Android 上也可以在对话中让 Agent 创建、查看、修改、启停或删除任务。

Android 入口是「设置 → 定时任务」。iOS 常规界面不提供这个设置入口；识别到支持 Duo 的折叠设备工作台后，聊天底部工具栏才提供「定时任务」。工作台的出现条件见[工作环境](workspace.md)。两者的执行时机与编辑方式存在以下明确差异。

## 任务列表

Android 列表按下次运行时间由近到远排列，没有下次时间的任务排在后面，同时间再按名称排序。每张圆角卡片包含名称、计划摘要、最多 160 字符的提示词预览、下次运行时间或「未安排下次运行」，并标明是用户手动创建还是 Agent 创建。右上方提供编辑和删除，右下方是启用开关。

没有任务时显示空状态说明和添加按钮；顶部加号也可以添加。删除直接移除计划，不另弹二次确认。关闭开关保留任务内容并取消后续触发；重新开启时按当前时间计算下次运行。

iOS Duo 的任务列表显示名称和启用开关、最多两行提示词、下次日期与时间，并提供「编辑」「立即运行」。列表支持滑动删除，顶部提供添加和完成。其任务按保存的列表顺序显示，不使用 Android 的时间排序。列表底部明确说明：任务在 Aether 活跃时执行，重新打开应用会补跑到期任务，后台执行由 iOS 管理。

## 创建与编辑

任务必须填写名称和提示词。名称或提示词只有空白时，保存按钮不可用。编辑已存在任务会保留其内容供修改；返回或取消不会保存未提交修改。

Android 的编辑页还可选择启用与否，默认启用。计划分为间隔、每天、每周三个互斥选项，切换后显示对应输入。顶部勾号提交并返回列表。

| 计划 | Android 编辑方式 | iOS Duo 编辑方式 |
| --- | --- | --- |
| 间隔 | 填写每隔多少分钟，可选活动开始与结束时间；默认 60 分钟 | 用步进控件选择 1 至 10080 分钟；默认 60 分钟，没有活动时段输入 |
| 每天 | 以逗号分隔填写多个时间，默认 09:00 | 用时间选择器选择一个时间，默认 09:00 |
| 每周 | 填写逗号分隔的星期数字和一个时间；1 是周一，7 是周日，默认周一 09:00 | 用各星期的开关多选，并使用时间选择器；默认周一至周五 09:00 |

Android 时间采用 24 小时的小时、分钟格式。每天的时间支持逗号、分号或换行分隔，重复时间去重后排序；每周的星期支持逗号、分号或空格分隔，也接受英文星期名称。不合法项不作为有效值。每天至少需要一个有效时间；每周至少需要一个有效星期和一个有效时间。这里名称与提示词决定勾号是否可点击，但计划没有有效值时，点击不会完成保存。间隔输入只接受数字，空值按 60 分钟处理，小于一分钟按一分钟处理。

iOS Duo 编辑器使用取消和保存按钮；每周没有选择任何星期时保存不可用。新任务默认启用，已有任务的启停在列表完成。

## 计划如何计算

每天、每周的时间按设备当前的本地时间计算，取当前时刻之后下一个符合计划的时间。

Android 的间隔以最近一次开始时间为基准，尚未开始过则以创建时间为基准。不填写完整活动时段时按普通间隔运行；开始、结束均有效时，仅安排在时段内。结束时间早于开始时间表示时段跨过午夜。每天可设置多个时间，每周可选择多个星期。

Android 会在应用启动、设备重启、系统时间或时区改变、应用更新后重新安排已保存任务。已经到期的有效计划会保留为待触发，而不是简单跳过。系统允许精确定时时优先精确触发；否则尝试系统闹钟或普通定时方式，因此系统限制可能影响到达时间，页面上的下次时间不是对绝对准点的承诺。

iOS Duo 在 Aether 活跃且聊天界面可见时约每 15 秒检查到期任务。应用关闭或被系统挂起时不保证准点触发；恢复到可检查状态后执行到期任务，不为错过的每个周期逐次补发。执行后以当前时间计算下一次；保存或重新启用也从当前时间重算。用户按「立即运行」可主动执行，即使任务关闭也可运行一次，关闭状态仍不安排下一次。

## 任务结果与聊天的关系

默认情况下，每个任务使用一个固定的专属聊天，多次运行在同一聊天中继续，用户可在聊天历史中查看提示词和 Agent 的结果。Android 的 Agent 管理还可以把任务关联到指定聊天，之后将提示词追加到该聊天；手动编辑页不提供关联聊天的输入。新建的任务聊天使用任务名称作为标题和当时的默认聊天模型；以后延续该聊天已有的选择。修改任务不等于清空聊天，删除计划也不主动删除已产生的聊天历史。

Android 每次触发将任务提示词加入对应聊天。该聊天已经运行时，新的要求进入排队，等当前回合完成后执行；不取消正在进行的任务。继续运行时保留该聊天选中的模型、技能、MCP、Phone Use 和浏览器能力。

iOS Duo 将到期要求送入对应的任务聊天，已有运行时也会排队，执行仍受普通聊天的模型和后台规则约束。其定时计划保存在本机，不与 Android 的计划共用。

Android 一次触发先安排下一次，再尝试本次执行。模型配置失效、执行启动失败或系统限制并不会使计划自动变成完成，也不自动关闭循环任务。用户可从任务列表关闭或删除后续计划。

任务的后台运行、完成通知及通知权限遵循[设置](settings.md)中的规则；任务到期不自动获得原本缺少的模型凭据或系统权限。
