# 设置、模型与应用数据

## 设置入口

设置首页列出通用设置、模型提供商、个性化、可靠性、扩展提供的设置页、Agent Skills、Pi Extensions、运行环境、使用统计、开发者和关于。各入口可显示当前语言和主题、启用的提供商、已配置数量、运行环境状态或版本等摘要。Android 另有定时任务、Phone Use、入门引导等入口；运行环境的具体操作见[工作空间](workspace.md)，Phone Use 和定时任务分别见 [Phone Use](phone-use.md) 与 [定时任务](scheduled-tasks.md)。iOS 在较宽屏幕上可同时显示设置列表和选中页面，在窄屏幕上逐级导航。

## 通用与个性化

语言可选 English、简体中文、فارسی、Русский；初始语言按设备语言决定。主题可选跟随系统、浅色和深色，默认为跟随系统。选择后应用界面使用对应语言和外观。

个性化页面提供自定义指令编辑和保存。指令会在开始 Agent 任务时加入上下文；保存后给出已保存反馈。

## 可靠性与后台运行

可靠性页面提供闲置重连超时，默认 360 秒，可在 30 至 3600 秒之间调整。支持后台持续运行的平台可设置在后台继续运行任务，支持本地通知时还可设置任务结束通知；两项默认开启。相关选项按设备能力显示。Android 使用前台服务让离开 Aether 后的活跃聊天继续运行；全部排队工作结束后，只有 Aether 不在屏幕上、并非主动暂停、存在最终结果且完成通知开启时才发提醒。通知不保证点击后直接打开对应会话。iOS 先以短暂后台时间衔接正在运行的任务；iOS 26 及更新版本会请求系统继续处理，系统可在条件允许时继续运行，并显示任务名称、最新活动及进度指示。此进度表示活动，不能当作已知完成百分比。系统分配时间到期时中断，保存部分输出并允许重试该轮。不同提供商对超时解释不同：明确可重试的失败会重试，响应已经开始后的含义不明确超时不会重发请求。

## 模型提供商

提供商列表显示已配置的服务及启用状态，允许添加、编辑、启用或停用和删除；空列表提示先添加提供商。新增流程依次选择认证方式、搜索并选择提供商、连接服务、选择模型并保存。认证方式包括订阅账号、API 密钥和使用运行环境中已有凭证；可用方式随提供商而变。

订阅登录可提供浏览器登录或设备代码登录：显示授权状态、打开授权或验证页面、复制设备代码，并在需要时继续输入认证信息；用户可取消认证或断开已有连接。API 密钥输入为保密字段；环境方式说明凭证取自运行环境，并可填写环境变量。连接时可填写基础 URL，获取模型期间显示进度，失败显示原因并允许重试。未取回模型时，可手动逐行添加模型 ID。模型列表支持逐项启用、全选和取消全选。

编辑及高级设置包括名称、提供商 ID、基础 URL、速度档位、User Agent、自定义请求头、环境变量和兼容模式。提供商 ID 只能使用小写字母、数字和下划线；无效时显示提示并阻止保存。速度档位留空使用提供商默认值。更换认证或连接信息后，可重新获取模型；手动模型和已获取模型都可参与选择。

提供商卡片显示名称、类型及已启用模型数，点卡片进入编辑；iOS 可在列表上滑删除。可以返回向导前一步，取消离开编辑；保存只在配置有效时可用。

高级选项中的名称用于识别实例，提供商 ID 用于区分实例，不能与现有 ID 冲突。请求头和环境变量以名称和值成对编辑，可添加和删除。兼容模式针对需要兼容行为的服务使用。若提供商拒绝 Developer 消息角色，开发者页会列出该提供商的回退标记；关闭标记后下次重新尝试 Developer 消息。

默认模型分别用于对话、标题生成、总结、命名和上下文压缩，初始均为自动；已选模型不可用时显示不可用。选择页在模型之前固定列出“自动”；标题生成、总结和命名还提供“无”。自动可显示将被选用的模型，模型选项显示提供商和模型名称，当前项有选中标记；搜索按名称过滤，点选即保存。总结的自动推荐与标题生成共用推荐模型。已关闭的提供商或模型不会作为可用选择。

自动推荐只从启用的提供商和模型中选择，按模型名称匹配以下优先级；同级按提供商 ID 和模型 ID 排序。没有匹配项时使用可用模型列表第一项：优先 GPT、Claude、Gemini，然后其他模型，同组按名称排序。没有可用模型时无推荐。

- 对话：Claude Fable 5、GPT-5.6 Sol、GPT-5.6 Terra、Claude Opus 4.8、Claude Sonnet 5、Gemini 3.5 Flash、Grok 4.5、Gemini 3.1 Pro、Kimi K3、DeepSeek V4 Pro、DeepSeek V4 Flash、GLM 5.2、Muse Spark 1.1。
- 标题生成、总结、命名：Gemini 3.1 Flash Lite、GPT-5.6 Luna、GPT-5.4 Mini、Claude 4.5 Haiku，再到名称含 mini、haiku 或 lite 的模型。总结采用标题推荐规则。
- 上下文压缩：Gemini 3.5 Flash、GPT-5.6 Luna、Claude 4.5 Haiku、Gemini 3.1 Flash Lite。

标题生成用于新对话的会话标题；总结用于对助手思考过程生成摘要。当前设置中“命名”和“上下文压缩”可选择并保存，但当前不会改变两端实际命名或手动压缩所用的模型。Android 中标题和命名都处于自动时，首次更改其中一个会同步另一项；之后各自可独立设置。

## 使用统计

统计页面刷新本地记录，展示 Token 总量、会话数、平均速度和平均延迟；没有可用数据时显示暂无。还可查看最近 7 天、Token 历史趋势、输入／输出／推理构成、缓存读取与写入、峰值日期、最大及平均单轮、记录轮次和近期速度。图表和数值随记录更新。Android 的每日柱图为最近 7 天，折线图为最近 14 天，近期速度柱图最多显示 12 个样本；峰值日期取这 14 天内的最高值。iOS 无用量时隐藏对应的每日和历史图，无速度样本时隐藏速度图，并额外显示平均单轮。速度为输出 token 每秒，延迟为首 token 等待时间；没有对应数据时显示暂无。

## 应用数据

“应用数据”可导出或导入设置、提供商、Skills 和对话。导出前提醒备份可能包含对话和 API 凭证，应妥善保管。操作显示进度或结果。导出日志包含运行诊断，已存储的凭证会被隐藏。

导出为完整应用数据 JSON，包含设置、提供商配置和凭证、当前及历史会话、Skill 包、可导出的会话记录以及扩展归档；导出提醒特别指出自定义请求头、环境变量等隐私内容。Android 确认后使用系统文件选择器保存，iOS 确认后使用系统分享流程。取消确认或文件选择不执行操作；成功和失败有反馈。

导入使用系统文件选择器读取备份，恢复设置、提供商、Skill、会话和备份内扩展，替换现有对应本地数据，而不是逐项合并。恢复后当前会话依据备份选择；不可用的已选 Skill 会被过滤，会话中的 MCP 选中状态被清除。iOS 在选择文件前明确要求确认替换，并在恢复失败时尝试恢复导入前的数据；Android 的导入入口直接选择文件。无效或无法读取的备份显示失败。当前聊天草稿不作为导入后继续编辑的内容。

## 开发者与诊断

历史自动清理默认开启，默认保留 6 小时，可设 1–168 小时；执行新命令时清理已结束且超过保留时间的输出，运行中的命令不受影响。Android 另有 Termux 就绪状态覆盖。导出日志单独使用系统导出流程，操作成功或失败显示反馈。重放 Alpine 设置预览使用模拟输出和等待，不修改实际运行环境；重放后续引导重新展示引导。Android 的更新测试会获取最新 GitHub Release，即便当前版本已经最新也显示更新提示。

## 关于与更新

关于页面显示 Aether、正式版版本号、作者 Zhou-Shilin、网站和隐私政策；Android 另提供 GitHub 链接及检查更新，iOS 不显示 APK 更新操作。关于页的“检查更新”显示正在检查 GitHub Releases；发现新版本时显示版本号并提供下载并安装，下载时显示进度或正在下载，下载期间不能重复启动。检查、下载或安装出现错误时向用户显示结果。应用更新入口以 GitHub Release 的 APK 为依据。

## 隐私政策

使用前尚未同意隐私政策时，应用显示不可通过点弹窗外部关闭的对话框，说明须阅读并同意，并可点击政策链接打开全文；打开失败会提示。同意后保存选择，之后不再重复提示，并启用统计初始化。拒绝会退出应用；再次启动仍需作出选择。设置中的关于页面也提供隐私政策链接。

## 在对话中管理

用户可请 Agent 读取通用、可靠性、Skills 和开发者相关状态，并修改允许的通用及可靠性设置；扩展提供的设置也可由支持该能力的 Agent 读取或修改。Agent 可检查脱敏诊断信息。模型提供商、模型、基础 URL、提供商 API 密钥和默认模型选择不在此设置管理能力内，仍须通过模型提供商设置操作。
