# Aether 产品规格

按用户使用场景阅读，具体行为在对应文档中集中描述。共同功能合并说明，设备限制和平台差异写在该功能所在章节。

文档从用户、功能的角度出发而不是从代码的角度出发编写，描述用户侧看到的行为模式。不得包含代码、代码文件路径。使用人类可读的文本，避免使用高度技术化的语言。

每次修改后，当且仅当更改涉及用户侧使用时可对文档进行增删。Bug 修复等不应写入文档。
