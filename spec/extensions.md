# Skills 与扩展

## Agent Skills

设置中的 Agent Skills 列出已安装项的名称、描述和启用开关；无项时显示空状态。展开可查看 ID、文件数、允许的工具、兼容性、来源和路径，并可移除。

列表按名称排序。内置 Create Extension Skill 用于让 Agent 创建、安装并验证扩展；它随应用同步，不允许移除。内置 Skill 与用户导入的 Skill 都有启用状态。启用是全局可用性，与某个聊天是否选择使用该 Skill 是不同的操作。

在尚未发送消息的新聊天中选择技能，会同时记为后续新聊天的默认选择；已有聊天中的选择只改变该聊天。新聊天只带入仍启用且可用的默认技能。取消某技能的选择时，也会移除这个聊天已激活的对应技能内容。

Android 添加页以“文件夹 / Zip / URL”分段切换来源，初始显示文件夹；iOS 将文件夹和 Zip 放在“本地”，URL 放在“远程”。选择本地项目会调用系统选择器；URL 为空时不能开始有效安装，安装期间显示进度，成功后清空 URL。远程支持 HTTPS GitHub 仓库和 Zip 地址。Skill 详情中“任意”表示没有限制允许的工具，而不是一个工具名称。

## Pi Extensions

Pi Extensions 页面分“已安装”和“发现”：已安装项显示名称、版本、描述、启用开关与操作；发现支持搜索并显示作者和每月下载量，可查看详情、安装或重新安装。加载、无结果、错误和重试均有对应状态。操作显示准备、下载、安装依赖、保存、重新加载和刷新阶段。

“发现”目录来自 pi.dev。Android 页面明确说明扩展作为可信代码运行，可以广泛访问 Agent、应用、运行环境和工作区；一个包可同时改变 Agent 和应用界面或逻辑。本地导入支持 JavaScript、TypeScript 和 Zip。已安装卡片按实际包含的资源显示 Pi Extension、Aether UI Extension、Native 入口、Skill、Prompt 和 Theme 的数量；只有软件包类型提供更新，导入项可移除。开关变更后重新加载，界面反馈启用或禁用状态。

包详情包含资源类型、依赖及 README；无法加载详情时给出重试。发现可能不兼容的包时，Android 在安装前展示原因和可能出现非预期 Agent 行为的警告，用户可取消或选择“仍然安装”。交互式终端 UI、终端主题、只提供 Prompt 模板、依赖桌面系统或特定处理器架构分别显示针对性的说明。进度还显示已用时间，并提示大型软件包可能需要几分钟；操作失败显示原因。扩展的文件已更改但某个运行中的环境拒绝重新加载时，显示重新加载错误，不能把文件变化等同于全部生效。

Android 的 Native Mod 状态与脚本扩展分开展示：正常状态显示已加载入口数及发现的包数，包变更需要重启应用；上次启动在应用稳定前中断时进入安全模式，跳过 Native Mod，并显示疑似入口与加载错误。用户可选择下次启动启用 Native Mod，或下次以安全模式启动；脚本扩展仍可使用。Native Mod 是 Android 专有能力，脚本扩展可在两端提供设置和界面，重新加载不要求重启应用。脚本加载错误单独列出扩展和错误。

## 扩展设置与界面

启用并加载的脚本扩展可以注册设置页；设置首页按扩展提供的顺序显示页，页内分类也按提供的顺序排列。扩展未注册设置时不出现对应入口。iOS 的原生设置页接收脚本扩展的页面、分类、字段和动作；扩展自己的原生组件和界面区域不作为设置控件导出。

设置控件可呈现开关、下拉选择、分段选项、单选、滑块、普通文本、数字、保密文本、多行文本、按钮和外部链接。也可显示说明、分隔线、状态标签、键值详情、结果提示、空状态和项目卡片。按钮或卡片可打开分类或执行动作，卡片可带启停开关、编辑、删除和多个操作；不可用的动作显示为禁用。选择或开关触发对应设置动作；iOS 的滑块在结束拖动时提交，文本字段在离开控件时提交。扩展响应后界面刷新，并可显示信息、警告或错误。

扩展还能提供输入框上方的组件、聊天列表末尾内容和覆盖当前界面的页面；它们只在扩展注册且满足显示条件时出现。关闭覆盖页返回原对话，不等于结束后台工作。

需要用户选择、确认或输入的扩展交互以对话框呈现。选择框逐项列出选项，点击即提交；输入框接受单行文字并显示扩展提供的提示；确认框显示扩展给出的说明。确认和输入使用「完成」提交，「取消」或关闭对话框则取消此次交互；关闭确认框相当于拒绝，不等同于同意。

## MCP Servers

服务按名称排序。未配置时显示“No MCP servers”和添加按钮；已有服务时顶部显示已配置、已连接和工具总数。卡片区分 connected、failed、auth required 和 not connected；卡片展示服务 ID、连接方式、连接生命周期、请求超时，以及对应的 URL 和请求头数、命令及参数和环境变量数，或 socket 地址。Tools、Resources 和 Prompts 操作把检查结果显示在卡片内；可单独重新连接、启用或停用、编辑、删除。HTTP 服务还提供 OAuth 按钮。

新增表单和编辑表单的连接生命周期可选首次使用时连接、会话开始即连接、保持连接、首次使用后保持连接；请求超时留空或 0 使用默认值。HTTP 传输可选自动、Streamable HTTP、SSE；协议可选 Legacy、Auto 或 2026-07-28。工具可以全部直接提供、仅通过代理、或填写自定义清单；还可指定包含／排除规则、工具名前缀、是否提供资源和需要审批的工具。列表字段支持逐行填写。保存前检查名称、连接字段和结构化输入；重复名称或无效配置显示错误。更改连接方式时旧方式专属字段被清空。

OAuth 授权页面包含打开授权 URL、粘贴完整回调 URL 或授权码和 Complete OAuth。授权成功后重新连接；清除 OAuth 凭证也会关闭连接。HTTP 认证可配置额外授权参数、客户端名称、主页和标志地址。授权失败、用户需要操作或服务需要认证时以状态或错误反馈。

新增服务需填写唯一名称，连接方式默认 Standard I/O，也可选 HTTP 或 Unix socket。Standard I/O 提供命令、逐行参数、环境变量和工作目录；HTTP 提供 URL、HTTP 传输方式、认证方式、令牌、请求头及 OAuth 参数；socket 提供路径。切换连接方式会清除原方式专属字段。HTTP 默认自动选择传输和认证，也可选择 OAuth、Bearer token 或无认证。OAuth 支持授权码或客户端凭证，并可设置客户端 ID、密钥、权限范围和回调地址等；跳过发行方验证会削弱安全性。

## Web Access

启用 Web Access 后，设置页提供搜索、来源核查、内容提取和提供商配置。Web search tools 总开关默认开启，修改后在下次重新加载扩展时生效。默认搜索提供商为 Auto；可配置各提供商的 API Key 和 Base URL，包括 OpenAI、Brave、Parallel、TinyFish、Search1API、Searchinfinity、Querit、Tavily、SERPdive、Kagi、Ollama Cloud、SearXNG、Exa、Perplexity、Gemini、AnySearch、xAI、Bright Data、SerpBase 和 Firecrawl。凭证字段可清空；不同服务提供对应专属选项。

高级设置可按顺序填写备用搜索提供商；无效或重复名称会报错。结果工作流可选 Summary review、Automatic summary 或 Raw results，默认 Summary review；审阅闲置超时默认 20 秒，范围 10–600 秒，默认自动打开审阅界面。可选择总结模型及部分提供商的搜索模型；SERPdive 检索深度默认 Krill，也可选 Mako 或 Moby。

Context Extraction 中，GitHub 仓库克隆默认开启，默认大小上限 350 MB、超时 30 秒，可设置缓存位置。YouTube 理解和本地视频分析默认开启，默认模型均为 gemini-3.6-flash；本地视频默认上限 50 MB，PDF 默认上限 20 MB。隐私和网络设置可控制新的 Firecrawl 请求、Gemini 浏览器 Cookie 读取、Chromium 配置、代理信任与允许范围、抓取域名允许和阻止列表；阻止规则优先。这些额外访问默认关闭，域名列表默认空。Firecrawl API 默认 v2，可选 v1；Bright Data 可填写搜索和解锁区域。

Web Access 首页先显示搜索总开关，再进入 Provider、Context Extraction、Privacy and network。Provider 分类随当前默认提供商变化，显示该服务相关的密钥、基础 URL 和专属设置；密钥以保密输入显示当前配置，清空会移除。更改任何 Web Access 设置后显示已保存及需要重新加载扩展才能应用的提示；密钥或基础 URL 使用相同的重新加载提示。填写有序备用路线后，单一默认提供商切回 Auto，按所填顺序在暂时性错误、配额或网络错误时回退。

“Research on the web”只向输入框追加多来源研究请求的开头，用户仍可编辑和发送。搜索、来源核查、抓取内容及读取内容时有各自的进行中和完成名称。支持自定义消息时，研究、内容就绪、访问错误、搜索工作流更新和 Gemini Web 账号状态显示对应消息；不支持自定义消息的界面在聊天末尾显示最近活动，并提供 Dismiss 收起。搜索审阅工作流中的闲置倒计时到期会自动提交审阅。

Summary review 搜索时结果逐个出现。每张成功结果卡默认勾选，显示查询、提供商、摘要预览，展开可查看回答和来源链接；取消勾选排除整张结果，失败卡显示错误且不能选。可全选或取消全选、增加查询、用 AI 改写查询，或选择其他搜索提供商重新搜索。查询和搜索尚在进行时显示等待状态；全部结束且有选中结果后自动生成摘要草稿，也可选择直接发送选中结果而不总结。

审阅页可选摘要提供商和模型、编辑草稿、填写可选反馈后重新生成、预览格式化摘要，或返回结果列表更改选择。批准时至少选中一张结果并有草稿；成功提交后显示确认并关闭审阅窗口，失败时保留页面并提示。取消会跳过此次审阅；返回只回到结果选择，不提交。预览可关闭、批准或重新生成；选中文字可针对选中部分输入反馈。自动摘要模式跳过审阅窗口直接生成摘要，Raw results 跳过审阅和摘要。

倒计时在搜索全部结束后才开始；点击、输入、按键、滚动、鼠标移动或新结果到达会重置闲置计时，可在页面调整至最多 600 秒。到期时自动提交当前选择及已有摘要；若没有选中项则使用已完成的成功结果。提交完成或失败后显示到期状态并倒计时关闭。自动打开失败时会提供手动打开地址。用户也可通过搜索历史命令浏览已保存的搜索或抓取记录，选择查看查询、结果数或 URL 内容信息，或删除；无记录时显示提示。恢复会话时只恢复一小时内的记录。

## Subagents

默认最多同时运行 4 个后台 Agent，默认最大轮次 0、宽限 5 轮、嵌套深度 2、汇合方式 Smart；定时、输出记录、Fleet view 和记住 Agent 默认开启，模型范围限制和严格定义文件默认关闭。默认 Agent mentions 为 Model，Widget 为仅后台。最大并发范围 1–1024，最大轮次 0–10000。汇合方式可选 Smart、Async、Group；工具描述可选 Full、Compact、Custom。隐藏默认 Agent、严格定义、工具描述和定时能力的部分更改在下一会话生效，设置操作显示反馈。

输入框上方 Agents 区显示运行和排队数量，最多列出 6 张卡片，其余显示数量。运行及排队卡片显示名称、状态、任务描述、当前活动、轮次、工具次数、Token 和耗时中已有的信息，提供 View 和 Stop；完成、失败或停止的卡片短暂保留 15 秒，提供 Result 和 Conversation。Widget 设为 Background only 时只显示后台 Agent；设为 Off 且 Fleet view 关闭时隐藏整个区块。

View 打开当前会话的覆盖式查看器，显示名称、任务、状态、工具次数、Token、耗时和已有对话；尚无对话时显示空状态。运行中或排队中的 Agent 可在查看器输入消息并提交引导，也可选择 Stop agent。停止或发送失败时显示 Agent 已不再运行等反馈。Close 关闭查看器。Result 将结果加入当前对话；Conversation 可查看会话内容。完成通知可包括状态、任务、轮次、工具次数、Token、耗时和结果预览。

消息须以 @名称 开头并带非空内容；单独的 @名称或无法识别的名称交给主对话。指向运行或排队中的 Agent 时直接发送引导，指向已有已结束会话时尝试恢复，失败会提示。指向尚未启动的可用类型时，Model 模式由模型结合当前对话发起任务，失败则尝试直接启动；Direct 模式直接启动，Off 关闭路由。@main 将后续文字交给主对话。记住 Agent 时可在完成较久后恢复其会话。类型页面显示名称、说明、来源和启用状态；重新加载读取项目、工作区和个人定义。创建定义动作只把请求填入输入框，等待用户发送，并要求在名称或用途未知时向用户询问。

Agents 设置可隐藏内置 general-purpose、Explore 和 Plan，选择未知或禁用类型时使用的后备 Agent（默认 general-purpose，填写 none 时拒绝），以及调整 Agent 定义读取和工具描述方式。模型设置可限制子代理使用的模型范围。

## 在对话中管理

用户可请 Agent 列出 Skills、通过支持的 HTTPS GitHub 或 Zip 地址安装、启用、停用或移除 Skill；也可请 Agent 列出、安装、更新、移除或重新加载扩展包，或调用扩展注册的命令。重新加载可能安排在当前轮结束后执行；操作失败时会返回错误。
